# CLAUDE.md

Before making ANY decision in this repository — feature, architecture,
dependency, refactor — read `FOUNDER.md` and apply its decision rules.

Quick version:
- Every change must reduce one of the four risks in FOUNDER.md. Name it.
- Simpler beats scalable. Boring beats clever. Delete before adding.
- LLMs explain and prioritize; deterministic rules detect. LLMs never make
  accounting decisions.
- The out-of-scope list in FOUNDER.md is not negotiable without written
  risk justification.
- Challenge feature requests, including mine.
